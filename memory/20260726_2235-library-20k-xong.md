## Sự thật cốt lõi
- **Catalog**: `library/catalog.db` (SQLite) · PDF gốc `library/pdfs/` · artifacts `library/works/<slug>/`.
- **CLI**: `python3 tools/library.py ingest|adopt|process|status|list|export-index` (chạy từ repo root).
  - `ingest` dedupe SHA-256; `process` gộp nhiều PDF/1 JVM (batch-size), resume theo `status`.
  - `export-index` → `web/public/library/index.json` + copy `.mxl` để web phát.
- **Web**: mode thứ 3 **Thư viện** (`web/src/Library.tsx`) — tìm kiếm, badge trạng thái, ▶ mở từng phần vào Player.
- **Bug đã sửa**: `.mxl` gộp bằng music21 làm alphaTab crash (`reading 'beats'`) → **đừng dùng music21 để gộp mxl cho alphaTab**; luôn phát file export chuẩn Audiveris (mvt riêng lẻ).
- Default score mới: `/library/yeu-xa-sheet-nhac/yeu-xa-sheet-nhac.mxl`.
