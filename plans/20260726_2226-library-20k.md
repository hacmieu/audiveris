## Bài toán
Người dùng có ~20k bản nhạc (PDF). Cần: catalog quản lý, pipeline OMR hàng loạt, tra cứu + phát trên web.

## PLAN — Kiến trúc

### Nguyên tắc
- **Catalog = SQLite** (`library/catalog.db`) — 1 file, không cần server, đủ cho 20k+ dòng.
- **File theo slug**: mỗi bản nhạc 1 thư mục artifacts, không đổi tên gốc tùy tiện.
- **Idempotent**: dedupe theo SHA-256; chạy lại không hỏng dữ liệu; resume được khi lỗi giữa chừng.

### Cấu trúc thư mục
```
library/
  catalog.db              # SQLite catalog
  pdfs/<slug>.pdf         # PDF gốc (dedupe sha256)
  works/<slug>/           # artifacts: .omr, .mxl (mvt*), log
web/public/library/
  index.json              # catalog xuất cho web
  <slug>/<file>.mxl       # bản phát được
```

### Schema (bảng `scores`)
| Cột | Ý nghĩa |
|---|---|
| slug (UNIQUE) | tên chuẩn hóa từ file |
| title | tiêu đề (MVP: từ slug; sau: OCR title từ `.omr`) |
| sha256 (UNIQUE) | dedupe PDF |
| pages | số trang |
| status | `pending` → `processing` → `done` / `failed` |
| omr_path, mxl_paths (JSON) | artifacts |
| warnings, duration_s, error | chất lượng + debug |

### CLI `tools/library.py`
- `ingest <pdf|dir>…` — đăng ký PDF vào catalog + copy vào `library/pdfs/`.
- `adopt <slug> --from <dir>` — nhận artifacts đã OMR sẵn (không chạy lại).
- `process [--limit N] [--batch-size K] [--dry-run]` — chạy Audiveris batch cho `pending`. **Gộp K PDF/lần gọi JVM** (Audiveris CLI nhận nhiều input) để né overhead Gradle/JVM.
- `status` / `list [--search]` — tra cứu.
- `export-index` — xuất `web/public/library/index.json` + copy `.mxl`.

### Web: chế độ **Library** (mode thứ 3 cạnh Player, OMR Viewer)
- Đọc `index.json`, ô tìm kiếm, bảng: tiêu đề / trạng thái / số phần.
- Bấm 1 phần (`.mxl`) → chuyển sang Player và `api.load(url)`.

### Ước lượng scale 20k (ghi để Act sau)
- 1 bản ≈ 30–60s OMR → tuần tự ≈ **10–14 ngày máy**. Giảm bằng:
  1. **Batch nhiều PDF / 1 JVM** (bỏ ~15s overhead Gradle mỗi lần) — làm ngay trong `process`.
  2. Chạy **N worker song song** (4–6 tiến trình, RAM ~2–4GB/JVM).
  3. Build app một lần (`installDist`) thay vì `gradlew :app:run` mỗi batch.
- SQLite đủ; nếu cần full-text lời nhạc → bảng FTS5 sau.
