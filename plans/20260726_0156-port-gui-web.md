## 0. Bối cảnh & kết luận nghiên cứu

Audiveris tách làm 2 nửa:

- **Engine OMR** — chạy headless được (đã verify batch). `Book`/`Sheet`/`SIGraph`/`Inter`/`Relation` load/mutate/export MusicXML không cần GUI.
- **Editor GUI** — ~289 file Swing/Java2D (`*/ui/*`), khóa chặt vào `java.awt` + `MusicFont` + `InterController`. **Không có REST API.**

File `.omr` = ZIP chứa `book.xml` + `sheet#N/sheet#N.xml` (JAXB) + `sheet#N/BINARY.png`.
Mỗi Inter trong XML có: `shape`, `grade`, `ctx-grade`, `staff`, `id`, `<bounds x y w h>`. Có 831 `<relation>`.
→ **Đây là nền tảng để render overlay web**: ảnh nền + các hộp Inter click được, tô màu theo độ tin cậy.

**Chốt chiến lược (chi tiết ở report):** KHÔNG compile Swing sang web (chiến lược C — bất khả thi). KHÔNG viết lại editor thuần JS trên MusicXML (chiến lược B — mất glyph↔Inter↔SIG). **Chọn chiến lược A: web UI mỏng + JVM edit-service bọc model/`UITask` hiện có.**

```
[Browser: React]  ──REST/JSON──►  [JVM service (Javalin/Spring)]  ──►  [Book/Sheet/SIGraph + UITask + ScoreExporter]
   ảnh + overlay Inter                loadBook / ops / export              đúng semantic Audiveris, có undo
   palette + selection                                                     ghi .omr, xuất .mxl
```

## 1. Mục tiêu tổng (Definition of Done cả dự án)

Trong browser, người dùng có thể: mở 1 `.omr`/PDF → thấy ảnh sheet + overlay ký hiệu nhận dạng → chọn 1 Inter sai → sửa (gán shape / xóa / thêm / nối relation) → undo/redo → lưu `.omr` → xuất `.mxl` → mở trong web player alphaTab để nghe.

**Không** cố gắng đạt 100% tính năng desktop trong lần đầu. Ưu tiên đúng vòng "nhận dạng → sửa → nghe".

## 2. Phân rã phase (mỗi phase là 1 vòng PDCA)

| Phase | Tên | Kết quả chính | Rủi ro |
|---|---|---|---|
| **P1** | Read-only overlay viewer | Extract ảnh + Inter→JSON, render overlay click-được trong `web/` | Thấp |

## 3. PDCA chi tiết — Phase 1 (làm trước)

### PLAN
Chỉ đọc, không sửa. Tạo overlay để chứng minh: ảnh + bounds Inter khớp toạ độ, click ra thông tin (shape, grade, id).

- **Do**:
  1. Script (Java `-run` hoặc Python) giải nén `.omr`, xuất `sheet#1/BINARY.png` + parse `sheet#1.xml` → `inters.json` `[{id, shape, grade, ctxGrade, staff, x, y, w, h}]`.
  2. Đặt vào `web/public/omr/` (png + json).
  3. Thêm route/tab `OMR Viewer` trong `web/`: `<img>` nền + `<div>`/canvas overlay tuyệt đối theo (x,y,w,h) scale theo zoom; màu viền theo grade (đỏ<0.5, vàng<0.7, xanh≥0.7).
  4. Click hộp → panel bên phải hiện shape/grade/id.
- **Verify (Check)**:
  - [ ] Overlay khớp ký hiệu trên ảnh ở 100% và khi zoom.
  - [ ] Số hộp = số Inter có bounds (≈857).
  - [ ] Click đúng Inter, panel đúng dữ liệu.
- **Act**: nếu lệch toạ độ → xử lý gốc toạ độ/scale ảnh BINARY; nếu chậm với ~857 hộp → chuyển canvas thay vì DOM.

### Không đụng tới trong P1
Không mutate, không server, không alphaTab. Giữ surgical.

## 4. PDCA khung cho các phase sau (tóm tắt)
