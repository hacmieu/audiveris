**`<select>` 20k option = không dùng được** (UX + DOM + network). Thay bằng **typeahead** + API `?q=&limit=`.

## Tư duy (ghi để bàn giao)
- **KISS**: chọn 1 bài = tìm → ≤20 gợi ý → open. Không framework nặng.
- **SOLID/S**: `OmrViewer` sửa sheet; `BookPicker` chọn book.
- **DRY**: cùng mô hình search như tab Thư viện; catalog = `library/works` / SQLite.
- **DevOps**: luôn **cap** response (`limit≤100`); không dump unbounded; path tới FTS5 khi 20k thật.
