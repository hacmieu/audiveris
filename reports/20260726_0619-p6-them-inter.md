## Do — đã làm gì

### 1. API (Java) — `OmrApiServer.java`
Endpoint mới:

```
POST /api/sheet/{n}/inter
body: {"shape":"NOTEHEAD_BLACK","x":1850,"y":390[,"w":24,"h":20]}
→ {"ok":true,"action":"added","id":5526,"shape":"NOTEHEAD_BLACK","links":0,"canUndo":true,...}
```

Luồng (bám sát nhánh 1-staff của `InterController.determineStaff`):
1. `InterFactory.createManual(shape, sheet)` → ghost inter (grade 1.0, manual).
2. `bounds` = rect từ click; nếu thiếu `w/h` → dùng `interline` làm cạnh mặc định.
3. `staffManager.getStavesOf(center)` → sort theo `distanceTo` → staff gần nhất.
4. `ghost.setStaff(staff)` + `ghost.setBounds(bounds)`.
5. `links = ghost.searchLinks(system)` → dò quan hệ ứng viên (stem, ledger…).
6. `AdditionTask(sig, ghost, bounds, links)` → `runTask` (đẩy vào history, đánh dấu dirty).

Tận dụng lại y nguyên: history undo/redo, `editLock`, `save`, CORS. Thêm helper `extractJsonInt` (parse số trong JSON).

### 2. UI (React) — `OmrViewer.tsx`
- Palette **"+ Thêm"** trong toolbar: `<select>` nhóm theo optgroup (Nốt / Thân-Đuôi / Dấu chấm / Dấu lặng / Hóa biểu / Khóa / Số nhịp / Vạch nhịp / Diễn tấu).
- Chọn shape → vào **chế độ thêm**: con trỏ crosshair, banner vàng nhắc, các ô overlay `pointer-events:none` để click rơi vào stage.
- Click lên bản nhạc → đổi toạ độ màn hình → pixel sheet (chia `zoom`) → `POST /inter`.
- Reuse `mutate()` → tự reload + cập nhật Undo/Redo/dirty + toast.
- Chọn "— tắt —" để thoát chế độ thêm.
